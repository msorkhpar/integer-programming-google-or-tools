# 9.3. Explaining Decisions

Turning a solved plan into answers people can act on: which rules shaped the plan, read from each
row's slack rather than from prices a MILP does not have; why each project is in or out, priced by
forcing the opposite decision and re-solving; what changed between two scenarios, project by
project, with the inputs and the money beside it; and one result written for planners, finance and
auditors from a single record of the run.
