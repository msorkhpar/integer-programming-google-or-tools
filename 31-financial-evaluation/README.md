# 7.2. Financial Evaluation

Where the money numbers in a capital-planning model come from: discounting a cash flow to one date
and the rate that does it, escalation and the difference between real and nominal dollars,
annuities, lifecycle cost and equivalent annual cost for options with different lives, and the
NPV-by-start-year table that lessons 6.4.1–6.4.4 put in the objective, rebuilt here from cash
flows, entry for entry.
