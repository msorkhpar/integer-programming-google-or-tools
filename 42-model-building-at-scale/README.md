# 11.1. Model Building at Scale

GridCap's large portfolio, 10,000 projects over 10 years, built in seconds and built right: how to
measure where a planning run spends its time, how to build the timing model from DataFrames as
whole columns instead of row by row, how to prove that a fast builder makes exactly the model of a
slow one, and how to generate 10,000-project portfolios from a seed with a test of what every one
of them must satisfy.
