# 4.5. CP-SAT Scheduling

Deciding which week, and which crew: CP-SAT's interval variables and the NoOverlap constraint, from
the OR-Tools job shop to GridCap's vegetation crews; cumulative resources for a pool of crews, a
capacity that drops for storm standby, and outage windows as domains; element, table and
forbidden-assignment constraints for method choices, offers and crew rosters, starting from the
OR-Tools nurse roster; and a full season schedule that minimizes risk-weighted lateness, checked by
an independent checker and turned into named crews.
