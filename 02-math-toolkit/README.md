# 1.2. The Math Toolkit

The linear algebra the rest of the course leans on, on GridCap's own numbers: a plan as a vector
and the rules as a matrix, checked with one line of NumPy; why a model's matrix is almost all
zeros and how solvers store only the rest; and the geometry that says where the best plan of a
linear model lies, and why yes/no decisions spoil it.
