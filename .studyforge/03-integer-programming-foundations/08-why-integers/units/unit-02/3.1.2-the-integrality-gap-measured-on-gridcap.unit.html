  16. The integrality gap

GridCap's finance partner has read lesson Yes/no decisions, and why rounding an LP fails's warning and asks a sharper question. "Your LP says the small portfolio could be worth $25,451k. Your MILP says $25,336k. Which number goes in the board pack, and how much should I trust the other one?" The answer is that both are useful, for different reasons: one is a plan, the other is a ceiling, and the distance between them has a name. This lesson measures that distance on GridCap, in five rules.

GridCap is a fictional utility's portfolio, generated for this course. None of its numbers describe a real company.

Every Allowed Plan Is a Point of the Relaxation, So the LP Value Bounds Every Plan

Recall the two models of lesson Yes/no decisions, and why rounding an LP fails. The MILP allows $x_i \in \{0, 1\}$; its LP relaxation allows $0 \le x_i \le 1$ and keeps every other row. Write $z_{LP}$ for the relaxation's optimal value and $z_{IP}$ for the MILP's ("IP" for integer program).

Take any plan the MILP allows. Each of its $x_i$ is 0 or 1, and 0 and 1 both lie between 0 and 1, so the same plan is also a point the relaxation allows; every other row is identical in both models. The relaxation found the best point it allows, so its value is at least the value of this plan. That holds for every allowed plan, including the best one:

A number that no plan can beat is a bound; when maximizing it is an upper bound, a ceiling. When minimizing, the same argument gives $z_{LP} \le z_{IP}$, a lower bound, a floor no plan can go under. The argument uses nothing about GridCap: any MILP and its LP relaxation obey it.

On GridCap small, $z_{LP} = 25{,}451.27$ and $z_{IP} = 25{,}336$. So the finance partner can read the LP value as "no plan under these rules can be worth more than $25,451.27k", and the MILP value as "this plan, worth $25,336k, is the best there is".

The argument works for any relaxation: any model whose allowed points include every plan the original allows. Dropping the whole-number rule is one way to relax; dropping a row is another. The more you drop, the more points are allowed, and the higher (looser) the ceiling. The next rule shows one.

A One-Budget Relaxation Is Solved by Hand: Best Value per Dollar, Then a Fraction

Lesson Yes/no decisions, and why rounding an LP fails asked why the LP stops partway through one project. For a model with one budget row and nothing else, the LP relaxation can be solved by hand, and the hand method shows why.

Each dollar spent on project $i$ earns $\text{npv}_i / \text{capex}_i$ of NPV. With fractions allowed, the best use of the budget is to spend it on the project with the highest NPV per dollar until that project is fully funded, then on the next best, and so on. When the next project no longer fits whole, buy the share that fits, $\text{room} / \text{capex}_i$, and stop: the budget is spent. Must-do projects are paid for first, because the row $x_i = 1$ leaves no choice.

Why is this the best point? Any point that spends a dollar on a lower-ratio project while a higher-ratio project is not fully funded can move that dollar across and gain value. So at the best point every project above the stopping one is fully funded and every project below it is not funded at all. This is the classic bound for the knapsack problem ("pick items of given size and value to fit one capacity", exactly GridCap's one-budget selection). The branch-and-bound of lessons Branching on a fractional variable to A knapsack branch-and-bound in 116 lines uses it at every step.

On GridCap small:

The hand bound, $25,852.87k, equals what GLOP returns for the model with only the budget and must-do rows. It is higher than the full LP's $25,451.27k because the hand method ignores the parent and alternative rows: here it funded both alternatives of group G030, which the full model forbids. It is still a valid ceiling, since the budget-only relaxation allows every allowed plan and more. Three numbers now line up, each a ceiling on the next:

The first drops the whole-number rule and two kinds of row, the second drops only the whole-number rule, and the third is the best plan.

Problem statement

A retail chain picks which shop refits to fund from one budget. Some refits are ordered by a safety inspector (must_do). Before running a solver, its analyst wants the ceiling on what any plan can be worth, computed without one.

Write fractional_bound(projects, budget) in bound.py. It returns the optimal value of this LP relaxation, with $P$ the projects and $M$ the must-do ones:

Compute it by hand, with no solver: pay for every must-do project in full; then go through the other projects in decreasing order of $\text{value}_i / \text{cost}_i$, funding each one whole while it fits; the first that does not fit gets the share $\text{room} / \text{cost}_i$ that the remaining room buys, and you stop. The tests' must-do projects always fit the budget, and their ratios are all different.

The Integrality Gap Is the Distance From the LP Bound to the Best Plan


The integrality gap of a model is how far its LP bound sits above the best plan. As an absolute number it is $z_{LP} - z_{IP}$, in $k. As a share of the best plan, which lets you compare portfolios of different sizes, it is





Some texts define it as the ratio $z_{LP} / z_{IP}$ instead; that is 1 plus the number above, so the two carry the same information. The gap is never negative, by the first rule. It is 0 exactly when the LP relaxation already has a whole-number best point.


Some models have that luck built in. The OR-Tools MathOpt sample writing_seminar.py assigns students to writing seminars, and it has a switch that solves the LP relaxation instead of the MILP. Adapted here with the sample's own sizes (50 seminars, 12 students per seminar, 5 ranked choices each) and a fixed seed:


Sets. $S$ the students; $J$ the seminars; $R_i \subseteq J$ the 5 seminars student $i$ ranked, $j_{i,k}$ the one ranked $k$-th. Parameters. $q$ the seats per seminar (15, then 11); $p_k$ the penalty for a $k$-th choice (0, 1, 5, 20, 100); $P = 1{,}000$ the penalty for a student left without a seminar. Variables. $x_{i,j} \in \{0, 1\}$ for $j \in R_i$: student $i$ takes seminar $j$; $y_i \in \{0, 1\}$: student $i$ gets none (in the LP relaxation, both in $[0, 1]$).







Both times the LP answer is already whole, so the gap is 0 and the MILP adds nothing. With 11 seats for 12 students per seminar, 50 students must go without (50 × 1,000 of the 50,052), and still no fraction appears. Each $x_{i,j}$ sits in one student row and one seminar row, and nothing else: an assignment, which is a network model. MIT's chapter on integer programming (see Further reading) opens with this point: when the rows have that network shape, solving the LP gives a whole-number answer. GridCap's budget row, whose coefficients are project costs, has no such shape, which is why it leaves a fraction.

The gap shrinks as the portfolio grows. The hand method of the previous rule explains why. The LP's answer is a whole-number plan plus a share of one project (two or so when the alternative and parent rows bind), so the LP's extra value is at most a project or two's NPV. A bigger portfolio has more total value to divide that by, and more small projects with which a real plan can fill the leftover budget nearly as well as the fraction does. On the medium portfolio the ceiling is within 0.006% of the best plan.


What the gap means in practice: a MILP solver keeps two numbers while it searches, the best plan found so far and the best ceiling it can prove, and it stops when they meet, or come within a tolerance of each other (lesson What "optimal at 0.01%" means on a $2B portfolio: HiGHS's default is 0.01%). Before any search, its ceiling is the LP bound (tightened by presolve and cuts, lessons Cutting planes: Gomory and cover cuts by hand and Presolve: what the solver removes first). So the integrality gap is the distance the search starts with. Two Correct Formulations Can Have Different Gaps


A formulation is one way of writing a rule set as variables and rows. Two formulations can allow exactly the same 0/1 plans and still have different LP relaxations.


Take GridCap's parent rule, "fund the child only if the parent is funded". Lesson Decisions, objectives and constraints: turning a planner's question into a model wrote it $x_c \le x_{p(c)}$. Here is another way: $x_c \le 2\, x_{p(c)}$. Check it on the four 0/1 cases. With the parent at 0, the row reads $x_c \le 0$, so the child is off. With the parent at 1, it reads $x_c \le 2$, which a binary always satisfies. Both rows allow exactly the plans the rule allows. Call the first tight and the second loose:




The optimum is the same, as it must be: the 0/1 plans are the same. The LP bound is not. On GridCap tiny, P004 (the child) and P003 (its parent) have the same share, 0.099, under the tight row, because P004 is worth more per dollar and the row lets it go no higher than its parent. The loose row lets the child sit at twice its parent's share, 0.128 against 0.064, so the LP buys more of the valuable child for less of the parent and its value rises to $3,811.04k. On medium, the loose row lets P065 reach 0.5 too, and the gap grows more than fivefold, from 0.006% to 0.033%.


So the gap belongs to the formulation, not only to the problem. A stronger (tighter) formulation is one whose LP relaxation allows fewer fractional points while allowing the same 0/1 plans, so its bound is closer to the best plan and the solver's search starts closer to the finish. The loose row is what a careless big-M row looks like: a constant ($M = 2$ here) larger than it needs to be. Section 6 (Formulation craft) is about choosing the strongest formulation, and lesson Aggregated vs. cumulative (disaggregated) forms shows the same effect for precedence over time.


A Small Gap Means a Close Bound, Not a Safe Rounding


A small gap is good news about the bound. It is not news about rounding. Return to lesson Yes/no decisions, and why rounding an LP fails's first trap, an invented two-project model:



Its integrality gap is $(101 - 100) / 100 = 1\%$: the LP value is an excellent ceiling. Yet the LP's point, rounded down, is worth 2. The bound and the point are different things. The gap compares two values; it says the best plan is worth almost as much as the LP claims. It says nothing about whether the best plan looks like the LP's answer, and here it does not: the LP funds A whole, the best plan leaves A out.


This is why the board pack gets the MILP's plan, and the LP value goes next to it as the ceiling that shows how little any other plan could add.

Summary


  • Every allowed plan is a point of the relaxation, so the LP value bounds every plan. A ceiling when maximizing, a floor when minimizing, for any MILP.
  • A one-budget relaxation is solved by hand. Must-dos first, then best NPV per dollar, then a share of the first project that does not fit. Dropping rows gives a looser but still valid bound.
  • The integrality gap is the distance from the LP bound to the best plan. On GridCap it is 3.9% on tiny, 0.455% on small and 0.006% on medium, and it shrinks as portfolios grow.
  • Two correct formulations can have different gaps. The loose parent row allows the same plans and a higher bound; a stronger formulation starts the solver's search closer to the finish.
  • A small gap means a close bound, not a safe rounding. A 1% gap can sit next to a rounded plan worth 2% of the best.

Design Note: Report the Bound Next to the Plan
