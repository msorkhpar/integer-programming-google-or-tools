# 7.4. Value Functions

Turning what a capital project is worth into one number per project and start year: the benefit
measures a utility uses (reliability as SAIDI and SAIFI, safety, emissions and NPV), normalizing
measures in different units so that no unit can decide the ranking, weights set by swing weighting
and read as prices, and the CIPT value function that the multi-objective models of section 8 and the
capstone optimize.
