# 6.3. Knapsack and Assignment

The two model families under most capital plans and work plans. A 0-1 knapsack picks yes/no items
under one capacity, and a table over budget amounts solves it exactly; each further resource adds a
row and makes it a multi-dimensional knapsack, where no single ranking rule and no table will do.
Several knapsacks sharing one list of items give the multiple knapsack, and when every item must be
placed at an agent-dependent size, the generalized assignment problem: GridCap's projects assigned
to its crews. The module ends with cover inequalities, valid rows read off a budget row that cut
fractional LP points away and close most of GridCap small's integrality gap before any branching.
