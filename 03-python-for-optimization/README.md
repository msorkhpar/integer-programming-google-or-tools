# 1.3. Python for Optimization

The Python a model needs around it: reading the planning team's files into the sets and parameters
a model indexes, rejecting bad rows before a solver sees them, giving every input a checked type,
and testing numerical code with tolerances, fixtures and tables of cases. GridCap, the running
dataset, is a fictional utility's portfolio, not real data.
