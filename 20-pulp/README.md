# 5.2. PuLP

PuLP, COIN-OR's Python modeling library, with CBC as its solver: a GridCap model built, inspected,
solved and proved against its MathOpt original, then the reading skills for PuLP code someone else
wrote, from its idioms and its silent bugs to a tested port to MathOpt.

The model lesson 5.2.1 ports is the multi-period timing model of lesson 6.4.1, in section 6, which
the course reaches later. You do not need to have read it: lesson 5.2.1 restates the model in full,
and where it compares with "lesson 6.4.1's MathOpt output", it shows that lesson's recorded output
on the page. Lesson 5.2.2 works on the one-period selection of lesson 1.1.1.
