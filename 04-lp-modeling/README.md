# 2.1. Modeling Linear Programs

The first models whose decisions are amounts rather than yes/no choices: splitting GridCap's
maintenance budget across its programs and solving it with MathOpt and GLOP; rewriting any LP into
standard form, and reading each row's slack and surplus; and three patterns that recur in every
industry: blending, network flows and multi-period carry-over.
