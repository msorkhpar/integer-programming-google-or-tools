# 15.1. Mock Interviews

Seven interview rounds built from the whole course. Five mocks each take one area of an optimization
engineer's job on a capital-planning tool: modeling, solvers, value, diagnostics and production. The
last two mix every area, the way a phone screen and an onsite loop do. Each question has a model
answer you open only after answering, the follow-ups an interviewer asks next, and the lesson that
teaches it. Each mock has trap questions built from common wrong answers, a whiteboard formulation
you write and then code against tests, and a second code practice. GridCap, the utility you
practised on, is fictional, and so is every company and number in these rounds.
